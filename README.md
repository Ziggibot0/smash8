# SMASH 8

An 8-bit platform fighter. Two fighters, three stocks, damage that turns into
knockback, one stage. Single file, no build step, no dependencies.

Made to run in any modern browser — including Microsoft Edge on an Xbox One —
and playable with a gamepad (standard mapping), a keyboard, or both.

## Play

Open `index.html` (or the published URL) and press **Start**.

| Action | Xbox pad | Keyboard |
| --- | --- | --- |
| Move | Left stick / D-pad | Arrows or A/D |
| Jump (double jump) | A | Space |
| Attack | X | J / Z |
| Shoot | B or Y | K / X |
| Pause | Start / Menu | Enter |
| Mute | Select / View | M |

Player 2 joins by pressing a button on a second pad on the title screen.

## Rules

Hit an opponent until their damage is high, then launch them past the screen
edge. Three stocks each. Last one standing wins.
